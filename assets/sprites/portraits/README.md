# Portraits

All portraits are SVG files, 256x320px. Godot imports them as textures.

Each character has a portrait file matching the key used in dialogue JSON `portrait` fields:
- `edmund.svg` — Edmund Hale
- `arthur.svg` — Arthur Crane (the killer)
- `thomas.svg` — Thomas Hale, Edmund's son, 14
- `rosie.svg` — Rosie Hale, Edmund's daughter, 6
- `mickey.svg` — Mickey Daws, alley criminal
- `rowe.svg` — Constable Rowe
- `mrs_webb.svg` — Mrs Webb, neighbour
- `mary.svg` — Mary Doyle, tenement woman
- `hargrove.svg` — Councillor Hargrove
- `webb.svg` — Silas Webb, journalist

Replace SVG files with final painted/illustrated versions when art is ready.
The SVG placeholders use the correct dimensions and are already wired into the dialogue system.
